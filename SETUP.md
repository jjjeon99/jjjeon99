# Installation

Copy the `README.md` and the `assets` directory into the **root** of your GitHub profile repository (the public repository named `jeajin99`). Commit both paths together.

```
jeajin99/
├── README.md
└── assets/
    ├── 3dgs-banner.gif
    └── 3dgs-banner-preview.png
```

The banner is an AI-generated conceptual visualization; it is not produced by a real 3DGS training/rendering pipeline. Replace `assets/3dgs-banner.gif` with your own exported 3DGS GIF when available.
